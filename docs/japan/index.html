4月9日（四）成田機場 銀座
​

  • 景點
    • Sotetsu Fresa Inn Ginza Sanchome 相鉄フレッサイン 銀座三丁目
  • 交通
    • LCB
      info
      1. 抵達與購票
        • 抵達航廈：JL736（來自曼谷）通常抵達成田機場 第 2 航廈。購買車票：在入境大廳的「巴士乘車券售票處」（LCB 櫃檯）購買前往 銀座站 的車票。票價：大人單程約 1,300 日圓，深夜班次（23:00 後）約 2,600 日圓。注意行李限制：LCB 通常規定每人僅限 一件 托運行李。
      2. 乘車地點
        • 在 第 2 航廈 1 樓 的 2 號 或 19 號 乘車處上車（請依櫃檯購票時指示為準）。
      3. 下車站點與步行
        • 下車站：請在 銀座站 (數寄屋橋) 下車。步行指南：下車後步行約 6-8 分鐘 即可到達酒店。朝向「銀座松屋 (Matsuya Ginza)」百貨方向走。酒店位於銀座三丁目，靠近「銀座一丁目站」或「銀座站」A13 出口附近。您可以參考 相鐵飯店官網的銀座三丁目交通指南 查看詳細地圖。
    • Access 特快
      info

      若要搭乘 Access 特快 (Access Express) 從成田機場直達酒店且不用轉車，您的目標車站是 「東銀座站」。這條路線會由京成電鐵銜接都營淺草線，雖然中途會經過多個站點，但只要選對班次，您全程無需下車轉乘。

      1. 如何選擇班次（關鍵）
        • 並非所有 Access 特快都直達銀座，購票或看螢幕時請務必確認：
        • 終點站方向：選擇開往 「羽田機場 (Haneda Airport)」 或 「西馬込 (Nishimagome)」 方向的班次。注意：不要搭到開往「京成上野」的車，那會在青砥站分岔，無法到達銀座。
        • 避開「機場快特 (Airport Kaitoku)」：如果該班次在淺草線內顯示為 「機場快特 (エアポート快特)」，它將不會停靠東銀座站。建議：搭乘在淺草線內顯示為「各站停車」或「快特 (特急/普通)」且終點是羽田機場的班次。
      2. 乘車步驟
        • 購票/進站：在成田機場第 2 航廈 B1 的京成電鐵櫃檯或自動售票機購買車票，或直接使用 IC 卡（如 Suica/PASMO）進站。
        • 月台：前往 1 號月台（標示為橘色的 Access Express）。
        • 下車站：在 東銀座站 下車（車程約 62 分鐘，票價約 1,330 日圓）。
      3. 到達後的步行路線
        • 從東銀座站出發，步行至「相鐵FRESA INN 銀座三丁目」約需 3-5 分鐘：從 A2 或 A8 出口 走回地面。朝向銀座三丁目方向步行。酒店位於銀座松屋百貨（Matsuya Ginza）後方的巷弄內。
      4. 溫馨提示
        • 行李：Access 特快是通勤型電車，沒有專門的行李架，若行李較多或正值通勤尖峰時段，車內可能會比較擁擠。
        • 時刻表：您可以透過 京成電鐵官方時刻表 或 Google 地圖 即時確認下一班直達東銀座的具體時間。
